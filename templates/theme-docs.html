Theme Contract Documentation

Build a new theme by adding one folder under app/themes/<theme-id>. If the contract is valid, the theme is auto-detected with no manual registration.

Open Create Form View Theme Catalog API
Contract Source app/themes/*
Sync Command npm run theme:sync
Auto-run npm run dev and npm run build

1. Required Folder Structure

Every theme must follow this exact structure:

app/themes/<theme-id>/
  theme.json
  shell.tsx
  pages.ts
  sections/index.tsx
  recipes/index.ts
  tokens.ts
  • <theme-id> must match theme.json.id.
  • Only one theme should set "isDefault": true.
  • If files are missing, the theme is ignored by discovery.

2. theme.json Example

{
  "id": "my-theme",
  "name": "My Theme",
  "description": "Custom independently packaged theme",
  "status": "stable",
  "isDefault": false
}

Keep IDs lowercase and folder-safe (letters, numbers, dashes).

3. Export Contract

Use these exact export names:

// shell.tsx      -> export const themeShell
// pages.ts       -> export const themePages
// sections/index.tsx -> export const themeSections
// recipes/index.ts   -> export const themeRecipes
// tokens.ts          -> export const themeTokens

Generated registries import these symbols directly.

4. Minimal Implementation Example

// shell.tsx
'use client'
import type { ThemeShellComponent } from '../types'

export const themeShell: ThemeShellComponent = ({ children }) => <>{children}</>

// pages.ts
import type { ThemePageRegistry } from '../types'
export const themePages: ThemePageRegistry = {
  // home: MyHomePage,
}

// tokens.ts
import type { ThemeTokenMap } from '../types'
export const themeTokens: ThemeTokenMap = {
  radii: { card: '16px' }
}

5. Create & Verify Workflow

1

Create app/themes/my-theme/ with all required files.

2

Implement the contract exports and update content/styles for your theme.

3

Run npm run theme:sync to regenerate registries and the shared manifest.

4

Open /api/themes and confirm your theme appears in the catalog.

5

Use the new theme from the Create form and AI Brand Generator selectors.

6. Generated Files (Do Not Edit Manually)

app/themes/generated/theme-shell-registry.generated.ts
app/themes/generated/theme-page-registry.generated.ts
app/themes/generated/theme-contract-registry.generated.ts
theme/theme-manifest.json

These files are produced by the sync script from your theme folders.
